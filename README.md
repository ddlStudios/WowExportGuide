# WoW Forever Guide - addon «Exportar personaje»

Addon para **WoW Forever** que exporta tu personaje (clase, raza, profesiones, PvP, equipo, estadísticas y talentos) para llevarlo a la
app *WoW Forever Guide*. Escribe `/wfg` en el juego.

- No tiene acceso a internet: solo guarda el texto de tu personaje en un archivo de tu PC.
- Con `/reload` (o al salir del juego) el juego escribe ese archivo, y el programa «Actualizar PJ WoW Forever» lo sube a la app.

## Instalar

Copia la carpeta `WoWForeverGuideExport` a `World of Warcraft\_forever_\Interface\AddOns` (o usa el programa «Actualizar PJ WoW Forever»,
que lo instala y lo mantiene al día).

## Versión

Versión actual: **1.9.7**. El programa del PC consulta `version.json` de este repositorio para saber si hay una nueva.
